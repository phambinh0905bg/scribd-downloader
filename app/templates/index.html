Trích Xuất Link Google Drive Cho IDM

Nhập đường dẫn Thư mục hoặc Tệp tin Google Drive bất kỳ. Hệ thống sẽ tự động quét toàn bộ thư mục lồng nhau và tạo danh sách link tải trực tiếp tốc độ cao để dán thẳng vào Internet Download Manager (IDM).

Mặc định quét sâu tối đa 10 tầng thư mục con lồng nhau.

Hệ thống quét tự động không cần key. Chỉ điền nếu thư mục cực lớn.

Nếu file báo "Quota exceeded" (Đạt giới hạn 24h), bạn có thể nhập Cookie tài khoản Google cá nhân để tải với hạn mức cao hơn.

Cách tải nhanh bằng IDM (Internet Download Manager):

Cách 1: Bấm nút "📋 Sao Chép Tất Cả (IDM)" bên dưới → Mở IDM → Chọn Tasks (Tác vụ) → Add batch download from clipboard (Thêm gói tải từ bộ nhớ tạm) → Chọn tất cả → Bắt đầu tải!

Cách 2: Bấm nút "📥 Xuất File .TXT" → Mở IDM → Chọn Tasks → Import → From text file.
